# procedural-cn-bgm

**纯 Python 程序化合成中国风纪录片配乐** — 无需 Suno/Udio 等外部音乐生成服务。

用 `numpy` + `scipy` 合成古琴（Karplus-Strong）、编钟（加法合成）、太鼓（扫频正弦）、弦垫、箫，并通过 **节拍锁定** 让每个镜头切换恰好落在乐句重拍上。

## 特性

- 🎵 **6 种中国乐器** 的物理/加法建模合成
- 🎬 **节拍锁定**：BPM = 60 / (单镜时长 / 8)，每镜 = 2 小节 4/4，剪辑点与重拍严格对齐
- 📜 **三幕编曲模板**：序（压抑）→ 征途（行进推峰）→ 归来（大调解决+留白）
- 🔊 **FFT 卷积混响**：1.7s 指数衰减大厅
- 🚫 **零外部依赖**：除 numpy/scipy/soundfile 外无需任何音乐 API 或模型

## 快速开始

```bash
pip install -r requirements.txt
python bgm_gen.py          # 输出 bgm_raw.wav
# 归一化到 -18 LUFS
ffmpeg -i bgm_raw.wav -af loudnorm=I=-18:TP=-2:LRA=11 -c:a pcm_s24le bgm.wav
```

## 适配你的视频

修改 `bgm_gen.py` 顶部三个常量：

```python
DUR = 177.245       # 视频总时长（秒）
SLOT = DUR / 22.0   # 总时长 / 镜头数
```

节拍锁定自动生效：每镜恰好 2 小节，镜头切换全部落在乐句重拍。

## 乐器合成原理

| 乐器 | 合成方法 | 关键参数 |
|------|---------|---------|
| 古琴 | Karplus-Strong | decay=0.9965，软拾音低通 |
| 编钟 | 加法合成 | 分音比 [1, 2, 2.98, 4.21]，分级指数衰减 |
| 太鼓 | 正弦扫频 + 噪声 | 90→42Hz 0.06s，鼓皮噪声低通 900Hz |
| 弦垫 | 多分音 × 3 组微失谐 | 慢包络 attack 1.5-2.5s |
| 箫 | 正弦 + 颤音 + 气声 | 5.2Hz 颤音，1.8-5.2kHz 带通气声 |
| 混响 | FFT 卷积 | 1.7s 指数衰减噪声 IR，25ms 预延迟 |

## 编曲结构

```
幕一·序    (0-25%): 低音持续音 + 心跳鼓 + 古琴碎片 → 镜末重击转场
幕二·征途  (25-77%): 大鼓 + 大提琴固定音型进场 → 镜10收薄 → 镜16-17滚奏推峰
幕三·归来  (77-100%): D小调→D大调解决 + 编钟 + 箫 → 收薄 → 留白收尾
```

调性：D 羽五声（D F G A C）→ D 大调五声（D E F# A B）。

## 混音建议

| 元素 | 目标 LUFS |
|------|----------|
| BGM 交付版 | -18 |
| 混入视频时衰减 | -9 ~ -11.5 dB（底衬 -27 ~ -29 LUFS） |
| 成片限幅 | -3 dBFS（预留 AAC 编码 ~1.5dB 超越量） |
